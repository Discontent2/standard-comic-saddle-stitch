# Production Checklist

## Story pass

- [ ] Page count is divisible by 4.
- [ ] Cover title is correct.
- [ ] Page order is correct.
- [ ] No missing page numbers, unless intentional.
- [ ] Speech bubbles read left to right and top to bottom.
- [ ] Captions do not cover important art.

## Art pass

- [ ] Every final page is 2063 × 3150 px or intentionally accepted.
- [ ] Important details are inside the safe zone.
- [ ] Background art reaches the bleed edge.
- [ ] No accidental UI, watermarks, hands, cropped borders, or chat artifacts.
- [ ] Dark pages have been brightened enough for print.

## Print pass

- [ ] PDF opens correctly.
- [ ] PDF page count is correct.
- [ ] PDF pages are single pages, not spreads.
- [ ] Fonts are flattened or embedded.
- [ ] One proof copy ordered before a full batch.

## Proof copy inspection

- [ ] No text chopped by trim.
- [ ] Binding does not hide important art.
- [ ] Colors are acceptable.
- [ ] Pages are in correct order.
- [ ] Cover looks good under normal room light.
